# Age of War-lite

Phaser browser game with lane combat, evolving ages, economy, units, and win/loss flow.

## Install

```bash
npm install
```

## Run

```bash
npm run dev
```

## Build

```bash
npm run build
```

## Preview

```bash
npm run preview
```

## Liivo Deployment

Build command: `npm run build`

Static output: `dist`

After deployment, add the Liivo URL to Noel's Game Hub under `age-of-war-lite`.
